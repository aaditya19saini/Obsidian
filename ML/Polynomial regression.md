Polynomial Regression is a technique that enables a linear model to fit **nonlinear data**
#### Scikit learn-  
- `PolynomialFeatures` ( this is used for performing data transformations)
- `LinearRegression` (to fit )


## working 
- It achieves this by adding powers of each feature as new features to the dataset, and then training a standard linear model on this expanded set of features.
- While a simple linear model assumes a straight-line relationship, Polynomial Regression allows the model to capture more complex, curvilinear relationships within the data.
