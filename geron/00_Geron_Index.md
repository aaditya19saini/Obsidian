# Hands-On Machine Learning (Geron) - Master Index

This directory contains condensed notes synthesized from **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (2nd Edition)** by Aurélien Géron.

## Knowledge Map

- [[Part I - Fundamentals of ML]]
  - Landscape of ML, linear models, gradient descent, metrics.
- [[Part II - Advanced ML Algorithms]]
  - SVMs, Decision Trees, Ensembles, Dimensionality Reduction.
- [[Part III - ANNs and Deep Learning]]
  - Keras API, Deep Network Training (Optimizers, Batch Norm).
- [[Part IV - Specialized Architectures]]
  - CNNs, RNNs, Autoencoders, GANs, and Reinforcement Learning.

> [!NOTE]
